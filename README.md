# E-School – Online Learning Platform

E-School is a fun, friendly online learning platform landing page that lets students learn on their own schedule. It combines playful illustrations, clear stats, and course listings to make e-learning approachable and engaging.

## ✨ Features

- **Hero Section** – "Learn With fun on any schedule" headline with illustrated live-class graphic, description, and "Get Started" CTA
- **Stats Grid** – Highlighted numbers: 1500+ Topics, 1800+ Students, 9K+ Test Tokens, 2000+ Students — each with icon and "Learn Anythings" tagline
- **Online Course Listings** – Course cards (e.g. "Modern Psychology") with image, title, designation, start date, seat count, and "Buy Course" CTA
- **Testimonial** – Student/user quote with profile photo
- **Call-to-Action Banner** – "Millions of people of all ages... are improving their lives with us" dark-themed motivational section
- **Footer** – Three-column link groups (Courses, Terms, Useful Links: Graphic Design, Web Design, Business, Marketing, Engineering) with copyright notice
- **Responsive Navigation** – Hamburger menu for mobile-friendly browsing

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18
- npm or yarn

### Installation

```bash
git clone https://github.com/your-username/e-school.git
cd e-school
npm install
npm run dev
```
